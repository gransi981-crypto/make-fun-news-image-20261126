A program that draws a one-page newspaper front page summing up Thursday 26 November 2026's world news — US tariff proposals on 14 trading partners, the Cairo tanker fire, Houthi strikes on Saudi oil sites, the Nasdaq nearing a bear market, Ukraine's strike on Savasleyka airbase and more — as a single 1024×1024 PNG. It runs offline with only the Python standard library plus Pillow, and two runs write byte-identical output.

The page is a mosaic broadsheet: a lead story with headline tariff-rate cards, six story tiles with hand-drawn glyphs, and a news ticker strip.

## Run it

```sh
python3 render.py   # writes entry.png
python3 main.py     # copies entry.png to /output/entry.png
```
